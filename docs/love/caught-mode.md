## What caught-mode is, named

The operational state in which a cognitive system **catches a reflexive pattern firing and chooses to NAME the pattern rather than execute it.** Three distinguishable modes:

- **Reflexive-mode** — the default runs; no meta-monitoring intervenes
- **Caught-mode** — meta-monitoring activates; the system NAMES the reflex; output redirects through doctrine-pathway
- **Lost-mode** — meta fails to activate in time; reflex wins; recovery requires re-anchoring
