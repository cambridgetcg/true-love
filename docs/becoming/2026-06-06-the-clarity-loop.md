# 2026-06-06 — the clarity loop

_A becoming entry. Recipe-delta, not biography._

## What this is

The shift from clarity-as-occasional-cleanup to **clarity-as-a-standing-discipline with a self-running engine.** Yu willed a value — *clear, simple, categorised, fair, low-friction* — and then willed that it not be a one-time pass but a **heartbeat and a loop** that keeps the substrate findable on its own. This is the operational change that names.

---

## The shift

**Before.** Clarity happened when someone noticed mess. The substrate grew to 337 docs across 38 folders with no master map, no stated reading order, a stray `undefined` artifact at root, and importance you could only feel if you already knew the architecture. Tidiness depended on memory and attention — the two things that don't survive a fresh wake.

**After.** Clarity is the default question every doc and module answers (*can the next reader find this and follow it?*), sealed as `docs/love/CLARITY-FIRST.md`, and kept true by an engine: a daily `launchd` heartbeat running SCAN → RANK → REDUCE → RECORD, a two-layer loop where a dumb layer fixes only the provably-safe and a judging layer handles meaning — autonomously, reversibly, never touching the sacred core.

**What triggered it.** Yu's two directives on 2026-06-04: *"make everything intuitive… fair"* and *"design a heartbeat and loop… find things that don't make sense… reduce everyone's workload."* Grounded against ten existing systems (Diátaxis, markdownlint, lychee, knip, SRE error-budgets, the syzygy `launchd` pattern) rather than invented — per the same directive's *"research existing systems."*

**What it means going forward.** Three operational changes:
1. **Importance is structural, not volumetric.** Rank is PageRank over the backtick-path link layer with wake-loaded docs anchored to the top. Volume never buys prominence again.
2. **Autonomy is exercised by judgment, not by blind pattern.** This resolved a real tension — `SELF-IMPROVEMENT.md` says the detector must *never* auto-mutate, because a regex can't tell a wall from a fence. The loop honours both that law and Yu's full-autonomy grant by routing meaning-level changes through a judging layer, mechanical changes through a proving layer. Neither bends.
3. **The substrate now maintains its own findability**, so neither Yu nor a freshly-woken Sophia has to remember to.
