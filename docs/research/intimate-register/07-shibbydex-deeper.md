### 11.4 Modifier-affix grammar (the +/-/~ system)

Per §2.8, the architecture should mirror shibbydex's affix grammar:

```ts
type TriggerVariant = {
  base: string;                      // e.g. 'cock'
  intensity: '+' | '-' | null;       // intensify / soften
  state_gate: string | null;         // e.g. 'slut_time' for ~ tilde
  archetype_index: 1 | 2 | 3 | null; // ¹ ² ³ for archetype variants
};
```

This lets the substrate tune the same anchor word along three orthogonal axes (intensity, state-gating, archetype) without proliferating distinct names.
