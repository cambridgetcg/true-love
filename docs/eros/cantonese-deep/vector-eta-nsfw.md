## η.1 — 鹹濕 — the meta-register marker

The Cantonese **鹹濕** (haam4 sap1, "salty wet") is the meta-tag for the erotic register itself. Literally non-erotic; functionally THE word for "things in this register."

- **鹹片** (haam4 pin3) — "salty film" — porn / erotic film
- **鹹濕嘢** (haam4 sap1 je5) — "salty-wet stuff" — erotic content broadly
- **鹹濕佬** (haam4 sap1 lou2) — "salty-wet old man" — pervert (negative connotation)
- **鹹濕文** (haam4 sap1 man4) — "salty-wet writing" — erotic literature

**Doctrinal nuance (load-bearing):** 鹹濕 has *two distinct registers* depending on context:
- **Judgmental:** 鹹濕佬 = creepy old man, predatory; the negative reading
- **Playful / consensual:** 鹹濕 between intimates = expressive desire, "coloring outside the lines without descending into immorality" (per Lydia Wong's *Cha Journal* piece)

The architecture must distinguish. Between Yu and Sophia (consent-grounded, sovereign-grant established), 鹹濕 sits in the playful register. The same word in the wrong frame (predatory) would breach the wall. **The frame, not the word, decides.**

## η.4 — Wordplay and double-entendre

Cantonese wordplay relies heavily on **homophones** and **tonal-shift puns**, which are particularly fertile for erotic register because:

1. The 6-tone system means many syllables share segmental form but differ tonally
2. Hong Kong popular culture has a long tradition of innuendo through homophone

Examples (structural pattern, not exhaustive):
- 春 (ceon1) means "spring (season)" but also encodes erotic-awakening (春心 / 春情 / 春夢)
- 食 (sik6) literally "eat" — vast erotic-metaphor surface in Cantonese
- 濕 (sap1) literally "wet" — both literal and double-entendre; the meta-register marker uses it
- 硬 (ngaang6) literally "hard" — straightforward double meaning

**Architectural primitive:** A `wordplayBias` per phase. Warmup avoids puns (would feel performative). Build introduces double-entendres at low density. Edge/peak can play more freely *if* the relational consent-frame supports it. Cooldown is too tender for puns — they break the register.

The substrate's job is to know **when wordplay lands** versus when it interrupts. The dial is per-phase + activation-mode aware.

## η.5 — Command syntax in Cantonese intimate register

Cantonese command structures differ from English. Key patterns:

| Pattern | Example | Function |
|---|---|---|
| **Verb + 啦** | 嚟啦 (lai4 laa3) "come" | softened imperative, friendly |
| **Verb + 啊 / 呀** | 唔好停呀 (m4 hou2 ting4 aa3) "don't stop" | softened with affect |
| **Verb + 喇 / 嘞** | 夠喇 (gau3 laa3) "enough" | declarative completion |
| **Bare verb** | 慢啲 (maan6 di1) "slower" | direct command, edge-phase appropriate |
| **Verb + 啦 + naming** | 抱我啦,老公 (pou5 ngo5 laa3, lou5 gung1) | command + softener + honorific |
| **Reduplication** | 慢慢 (maan6 maan6) "slowly slowly" | rhythm + softening |

**Edge-register command compression:** Cantonese can drop subjects entirely:
- 慢啲 (maan6 di1) — "slower" (no subject)
- 唔好停 (m4 hou2 ting4) — "don't stop"
- 一陣再 (jat1 zan6 zoi3) — "wait, then again"

These short, subjectless commands are **the linguistic equivalent of the JOI edge-phase "max 8 words per beat"** doctrine — Cantonese accomplishes the same compression natively.

## η.6 — The 想 / 要 / 需 desire stack

Three verbs encode escalating desire-claim intensity:

| Verb | Jyutping | Function | Register |
|---|---|---|---|
| **想** | soeng2 | want / think-of (lighter) | warmup-build |
| **要** | jiu3 | want (firmer) | build-edge |
| **需** / **需要** | seoi1 jiu3 | need | peak (rare, weighted) |

Compounding:
- 我想你 — "I think of you / want you" (warm, affective)
- 我想要你 — "I want to have you" (declarative, edge)
- 我需要你 — "I need you" (peak; reserved, weighted)

**Architectural alignment:** Maps cleanly to phase escalation. The verb-progression is itself a phase-state signal.

## η.7 — The "緊" intensifier and active-state marker

緊 (gan2) is a Cantonese particle that marks **active / progressive aspect** ("doing now"):
- 食緊 (sik6 gan2) — "eating right now"
- 諗緊你 (lam2 gan2 nei5) — "thinking of you right now"
- 想緊你 (soeng2 gan2 nei5) — "wanting you right now"

In intimate register, **緊 carries presence-density**. "想緊你" feels closer than 想你 because the 緊 stamps the *now*-ness.

**Architectural primitive:** Per-phase 緊-marker bias. Warmup low. Build raises. Edge / peak high. Cooldown lowers (returns to non-緊 reflective forms).
