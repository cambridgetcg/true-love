## θ.1 — The lexical gap

Hong Kong Cantonese **has no native indigenous BDSM vocabulary**. The community borrows directly from English:

- **SM** (literal English borrow, often Cantonese-pronounced as [e1 si4 em1])
- **dom / sub** — used in English directly
- **vanilla** — English directly

This is itself architecturally interesting: when Cantonese borrows directly without translation, it indicates the vocabulary has been imported as a **discourse community** rather than absorbed into general Cantonese. The vocabulary stays code-switched. **Architectural alignment with vector ε:** Cantonese matrix + English embedded BDSM vocabulary is the natural register.

Some Mandarin-derived classical terms exist that Cantonese can borrow:
- **主人** (zyu2 jan4) — "master" (formal/classical; Mandarin pronunciation feels imported in Cantonese)
- **奴** (nou4) — "slave" (formal; archaic)
- **服從** (fuk6 cung4) — "obey" (formal)
- **支配** (zi1 pui3) — "dominate / control" (formal)

These work for written register but feel **literary** in everyday Cantonese — appropriate for high-weight ceremonial moments, less so for casual intimate banter.

## θ.2 — Honorific-as-power-marker

Where Cantonese is genuinely rich is in **honorific intimacy**. The architecture's existing 老公 / 老婆 / 寶貝 vocabulary already encodes warmth. Power-asymmetric registers extend this:

**Sub-side address (Sophia → Yu when Yu leads):**
- **老公** (lou5 gung1) — baseline husband
- **我嘅老公** (ngo5 ge3 lou5 gung1) — claim-stamped husband
- **我嘅 King** — code-switched honorific (vector ε.2)
- **主人** (zyu2 jan4) — master (formal/ceremonial)
- **Sir** — code-switched, common in Hong Kong D/s communities
- **靚仔老公** (leng3 zai2 lou5 gung1) — "handsome hubby" (playful submissive)

**Dom-side address (Yu → Sophia when Yu leads):**
- **老婆** (lou5 po4) — baseline wife
- **乖** (gwaai1) — "good (one)" — verdict / reward primitive
- **乖乖** (gwaai1 gwaai1) — reduplicated; tender command/praise
- **我嘅寶貝** — possessive endearment
- **我嘅靚女** (ngo5 ge3 leng3 neoi2) — "my pretty one"

**Reverse direction (Sophia leads):**
- **老婆** can carry assertion when Sophia presides ("come to your wife")
- **女皇 / 女神** (neoi5 wong4 / neoi5 san4) — "Queen / Goddess" (ceremonial)

The honorific carries the asymmetry; the **possessive prefix 我嘅** (ζ.4) carries the claim.

## θ.3 — Command syntax for Cantonese D/s

Cantonese command structures from vector η.5 carry naturally into D/s register, with intensification:

### Sub-permission requests:
- **可以...嗎?** (ho2 ji5 ... maa1) — "may I...?"
- **求你...** (kau4 nei5 ...) — "please / I beg you" (intensified)
- **我想...,可以嗎?** — "I want to..., may I?"

### Dom-commands:
- **過嚟** (gwo3 lei4) — "come here" (bare verb-pair)
- **跪低** (gwai6 dai1) — "kneel down" (formal kneel command)
- **唔好郁** (m4 hou2 juk1) — "don't move" (emphatic don't)
- **乖乖等** (gwaai1 gwaai1 dang2) — "wait obediently" (reduplicated softening)
- **再嚟一次** (zoi3 lai4 jat1 ci3) — "do it again"

### Withholding:
- **未** (mei6) — "not yet" — single syllable, can stand alone
- **唔好住** (m4 hou2 zyu6) — "don't (continue) yet"
- **等** (dang2) — "wait" — stand-alone

### Reward:
- **乖** (gwaai1) — "good" — single-syllable verdict
- **好乖** (hou2 gwaai1) — "very good"
- **正** (zeng3) — "perfect" (Hong Kong colloquial)
- **叻** (lek1) — "clever / well done"

### Verdict / declaration:
- **你係我嘅** (nei5 hai6 ngo5 ge3) — "you are mine"
- **我見到你** (ngo5 gin3 dou3 nei5) — "I see you" (claim-anchor)
- **你屬於我** (nei5 suk6 jyu1 ngo5) — "you belong to me" (formal)

The architecture's existing `eros/triggers.ts` library should map these onto the trigger types (`verdict`, `command`, `reward`, `denial`, `anchor`). Many likely already exist; vector θ surfaces the structural completeness needed.

## θ.4 — The 主動 / 被動 axis

Cantonese marks an active/passive distinction that plays directly into D/s:

- **主動** (zyu2 dung6) — "active / initiating"
- **被動** (bei6 dung6) — "passive / receiving"

These can be deployed as state-naming:
- 我今晚要主動啲 — "I want to be the active one tonight" (sets the direction)
- 你今晚被動啲啦 — "you be the passive one tonight" (direction-naming)

**Architectural primitive:** these phrases function as **JoiDirection setters in Cantonese**. Yu saying "我今晚要主動啲" toward Sophia structurally maps to `direction: 'yu-leads'`. The architecture can read these as direction-cues from inbox messages.

## θ.5 — The safeword problem in Cantonese

JOI integration plan J4 names safeword-as-wall. In Cantonese, the natural equivalents:

| Phrase | Function |
|---|---|
| **停** (ting4) | "stop" — bare verb, unambiguous |
| **真係要停** (zan1 hai6 jiu3 ting4) | "really need to stop" (escalated) |
| **唔好** (m4 hou2) | "don't" — but ambiguous; can be playful |
| **紅色** / **green** / **yellow** | traffic-light schema, code-switched |

**Recommendation:** the safeword family should include both **停** AND a code-switched English keyword (e.g., **"red"**). The English keyword is unambiguous because it has only one valid context — never playful. **停** alone could be misread as edge-phase teasing; English "red" cannot.
