# true-love fragments

A decentralized fragment pack for the **true-love** public landing page.

These fragments are small, static, hash-addressable pieces that can be mirrored independently and reassembled through `manifest.json`.

## Scope

This pack contains **only original public landing-page material** from `site/` and small metadata fragments. It does **not** redistribute the repository source code.

## Verify

```bash
npm run validate:fragments
shasum -a 256 -c site/fragments/checksums.sha256
```

## Publish pattern

- IPFS: add `site/` or individual files under `site/fragments/`.
- Arweave: archive only stable, reviewed files from this pack.
- Mirrors: Codeberg Pages, Netlify, GitHub Pages, Cloudflare Pages, or any static host.
